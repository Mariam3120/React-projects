ეტაპი 1: ფაილების შექმნა და "მკვდარი" ვიზუალი (UI First)
ამ ეტაპზე ლოგიკა და State არ გვჭირდება. ჩვენი მიზანია, ეკრანზე უბრალოდ დავხატოთ ლამაზი დიზაინი. src ფოლდერში შექმენით ახალი ფოლდერი სახელად components და შიგნით შექმენით შემდეგი ფაილები:

Header.jsx:

შექმენით სტანდარტული კომპონენტი.

დააბრუნეთ <header> თეგი კლასით className="header". შიგნით ჩაწერეთ პროექტის სათაური.

BadgeCard.jsx (ინდივიდუალური ბარათი):

შექმენით კომპონენტი. ეს იქნება ერთი ცალი ბეჯის ვიზუალი.

მთავარ div-ს მიეცით className="badge-card".

შიგნით ხელით ჩაწერეთ დროებითი მონაცემები (მაგ: სათაურში "გიორგი", პარაგრაფში "Frontend Developer").

დაამატეთ წაშლის ღილაკი className="delete-btn".

BadgeList.jsx (ბარათების კონტეინერი):

შექმენით კომპონენტი. მთავარ დივში დაამატეთ სათაური "გენერირებული ბეჯები".

მის ქვეშ შექმენით div კლასით className="badge-grid".

ყურადღება: დააიმპორტეთ BadgeCard ამ ფაილში და დროებით, ხელით გამოიძახეთ 2-3-ჯერ (<BadgeCard/>), რომ დაინახოთ როგორ ჯდება ეკრანზე.

RegistrationForm.jsx (ფორმა):

შექმენით კომპონენტი, დააბრუნეთ <form> კლასით className="form-card".

შიგნით დახატეთ: სახელის <input> (კლასი form-input), 2 ცალი <input type="radio"> პოზიციისთვის და 1 <input type="checkbox"> სპიკერისთვის. დაამატეთ Submit ღილაკი (className="submit-btn").

App.jsx (მთავარი შეკვრა):

წაშალეთ შიგნით რაც წერია. მთავარ დივს მიეცით className="app-container".

დააიმპორტეთ და ერთმანეთის მიყოლებით გამოიძახეთ: <Header/>, <RegistrationForm/> და <BadgeList/>.

👉 თუ ამ ეტაპს მორჩით, ეკრანზე უკვე უნდა ხედავდეთ ლამაზ, მაგრამ უმოქმედო საიტს.

ეტაპი 2: მონაცემების მიწოდება (Props & Dummy Data)
ახლა უნდა ვისწავლოთ, როგორ გადავცეთ მონაცემები ერთი კომპონენტიდან მეორეს.

მონაცემების შექმნა (App.jsx):
კომპონენტის შიგნით (return-მდე) შექმენით დროებითი მასივი:

JavaScript
const dummyData = [
{ id: 1, name: 'გიორგი', role: 'Frontend', isSpeaker: true },
{ id: 2, name: 'მარიამი', role: 'Backend', isSpeaker: false }
];
გადაეცით ეს მასივი BadgeList-ს Prop-ად: <BadgeList participants="{dummyData}"/>

მონაცემების მიღება (BadgeList.jsx):

მიიღეთ participants პარამეტრებში (გამოიყენეთ ობიექტის დესტრუქტურიზაცია { participants }).

ამოიღეთ ის 2-3 ხელით ჩაწერილი <BadgeCard/> და მათ ნაცვლად გამოიყენეთ .map() მეთოდი.

map-ის შიგნით გამოიძახეთ <BadgeCard/>. აუცილებლად გაატანეთ key={user.id} და მთლიანი იუზერი პროპად: user={user}.

ბარათის გაცოცხლება (BadgeCard.jsx):

მიიღეთ { user } პროპად.

ახლა ხელით ჩაწერილი ტექსტების ნაცვლად ჩასვით {user.name} და {user.role}.

პირობითი დიზაინი: გამოიყენეთ ტერნარული ოპერატორი მთავარ დივზე. თუ user.isSpeaker არის true, მიეცით კლასი "badge-card speaker", თუ არა — უბრალოდ "badge-card".

👉 ახლა ეკრანზე უნდა დაინახოთ ის მონაცემები, რაც dummyData მასივში გიწერიათ!

ეტაპი 3: აპლიკაციის გაცოცხლება (State & ლოგიკა)
დროა გავაკეთოთ რეალური ფორმა და წაშლის ფუნქცია!

მთავარი State (App.jsx):

წაშალეთ dummyData და მის ნაცვლად შექმენით რეალური State: const [participants, setParticipants] = useState([]).

ფორმის ლოგიკა (RegistrationForm.jsx):

შექმენით ერთიანი State ობიექტი ფორმისთვის: const [formData, setFormData] = useState({ name: '', role: 'Frontend', isSpeaker: false }).

ინფუთებს მიაბით შესაბამისი value (ან checked ჩექბოქსზე). ასევე თითოეულს გაუწერეთ name ატრიბუტი ზუსტად ისე, როგორც State-ში გიწერიათ!

დაწერეთ handleChange ფუნქცია [e.target.name] სინტაქსის გამოყენებით და მიაბით ყველა ინფუთის onChange-ს.

მონაცემების დამატება (App.jsx -> RegistrationForm.jsx):

App-ში შექმენით handleAddParticipant ფუნქცია. მან უნდა მიიღოს ახალი ობიექტი და Spread (...) ოპერატორით ჩაამატოს participants State-ში.

ეს ფუნქცია პროპად გაატანეთ ფორმას. ფორმის onSubmit-ის დროს შეაჩერეთ რეფრეში (e.preventDefault()) და გამოიძახეთ ეს ფუნქცია.

წაშლის ლოგიკა (⚠️ Prop Drilling):

App-ში შექმენით წაშლის ფუნქცია (handleDeleteParticipant), რომელიც .filter()-ით ამოშლის ელემენტს id-ის მიხედვით.

ეს ფუნქცია ჯერ უნდა გაატანოთ <BadgeList/>-ს Props-ად.

BadgeList-მა ეს ფუნქცია უნდა მიიღოს და პირდაპირ გადააწოდოს ქვევით, თითოეულ <BadgeCard/>-ს .map()-ის შიგნიდან.

BadgeCard-მა უნდა მიიღოს ეს წაშლის ფუნქცია და მიაბას თავის "X" ღილაკს (onClick={() => onDelete(user.id)}).
